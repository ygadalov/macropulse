# Спецификация MacroPulse

Документ фиксирует архитектуру и стандарты, по которым добавляются новые классы данных (ставки, ОФЗ, макро). Правило проекта: **один и тот же код работает с `file://` и с GitHub Pages**, сеть нужна только для догрузки новых данных.

## 1. Общая архитектура

```
index.html          — оболочка (разделы, панели, настройки)
src/main.js         — логика: слой данных, модели прогноза, рендер
src/styles.css      — тема (dark, JetBrains Mono)
src/fonts.css       — шрифты data-URI (без внешних файлов и CDN)
src/vendor/         — Chart.js 4.x UMD (локально)
fx-history.js       — локальная база данных (window.FX_HIST)
docs/               — спецификация, roadmap
```

Принципы:

1. **Офлайн-first.** Старт страницы не делает ни одного сетевого запроса: список инструментов, график и лента строятся из локальной базы.
2. **База как JS-файл.** `fetch()` локальных JSON с `file://` в Chrome запрещён, поэтому база подключается через `<script src>` и публикует глобальный объект.
3. **Дельта поверх базы.** Новые дни догружаются с источника, пишутся в память и в `localStorage` (`fx:delta`), кнопка «Сохранить базу» сшивает базу с дельтой и перезаписывает файл базы.
4. **Ноль внешних CDN.** Все библиотеки и шрифты — в репозитории. Приложение не должно зависеть от доступности чужих доменов, кроме источников данных.

## 2. Формат базы (`fx-history.js`)

```js
window.FX_HIST = {
  generated: "2026-11-04T12:00:00.000Z",  // когда файл собран
  from: "2016-11-03",                     // первая дата
  to: "2026-11-04",                       // последняя дата
  lastDate: "2026-11-04",                 // последняя дата установки курса
  ids: ["AUD", ...],                      // коды валют (54)
  names: { "AUD": "Австралийский доллар", ... },
  cur: { "USD": { "2016-11-03": 63.9, ... }, ... }  // КОД -> {ISO-дата: руб за 1 ед.}
}
```

- Значение — всегда **рублей за 1 единицу валюты** (`Value / Nominal`). RUB = 1, в `cur` не хранится.
- Кросс-курсы без рубля считаются через рублёвые курсы обеих валют.
- Дни без установки курса (выходные, понедельники, госпраздники РФ) в базе отсутствуют; при чтении применяется forward-fill.

## 3. Конвейер обновления данных

1. `missingRateDays(endISO)` — список дней установки ЦБ в `(lastDate; сегодня]`.
2. `loadMissingDays(days)` — подневная догрузка с зеркала, 12 параллельных воркеров (замеренный оптимум; 16+ вызывает троттлинг по IP), ретраи ×3, резервный JSONP-канал (`daily_jsonp.js`, колбэк `CBR_XML_Daily_Ru`, строго последовательно — имя колбэка у зеркала одно).
3. Каждый удачный день → `dbPut()` → память + дебаунс-запись дельты в `localStorage`.
4. Бейдж «+N дн. не сохранено» показывает размер несохранённой дельты; `beforeunload` напоминает сохранить (текст диалога браузеры не позволяют менять — антиспам).
5. «Сохранить базу»: File System Access API (`showSaveFilePicker`, хэндл кэшируется в IndexedDB `fx-local`) — прямая перезапись `fx-history.js` в Chrome/Edge; иначе — скачивание с тем же именем. После сохранения `window.FX_HIST` в памяти обновляется, дельта обнуляется.

## 4. Стандарт для новых классов данных (ставки, макро)

Каждый новый класс = **реестр индикаторов + адаптер источника + файл(ы) базы**:

- Ряд индикатора: `{ "КОД": { "ISO-дата": значение } }` — тот же формат, что `cur` валют.
- Метаданные индикатора: `{ код, название, источник, частота, единицы, метод forward-fill }`.
- Адаптер: тонкая функция «догрузить с `lastDate` по сегодня», пишет через общий `dbPut`-механизм.
- Источники:
  - **MOEX ISS** (`iss.moex.com/iss/...`) — JSON, без ключей: кривая бескупонной доходности ОФЗ (`engines/stock/zcyc.json`, история с 2014), котировки ОФЗ (`engines/stock/markets/bonds/boards/TQOB`), индексы. Проверено 2026-11-04.
  - **ЦБ РФ** — официальный API XML/SOAP; для редких рядов (ключевая ставка ~8 изменений в год) допустим ручной/скриптовый снимок в базу.

## 5. Модели

- Краткосрочный прогноз: ансамбль damped Holt + Theta + наивный дрейф на log-ряде; точка — медиана трёх; полоса 90% — робастная σ (MAD) + разброс моделей.
- Долгосрочный тренд: лог-линейная регрессия (OLS), R² как мера значимости.
- Для доходностей/ставок (планируется): mean-reversion и динамический Нельсон–Сигель по параметрам кривой ZCYC — Holt-ансамбль к таким рядам не применять без адаптации.

## 6. Ограничения инфраструктуры

- Зеркало режет запросы по IP; мобильный CGNAT даёт общий «исчерпанный» IP — поэтому догрузка только дельтой, а не перезапросом истории.
- Приложение должно работать из РФ без VPN.
- GitHub Pages: кэш CDN ~10 минут после коммита; автообновление базы — через GitHub Actions (планируется), а не через кнопку у посетителя (кнопка пишет на диск посетителя).
