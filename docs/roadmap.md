# Roadmap MacroPulse

Ценность проекта — анализ и прогноз, а не показ данных. Каждый этап добавляет класс данных **вместе с аналитикой** по нему.

Статус на 26.11.2026: раздел FX завершён по запланированному функционалу и UX/UI (локально и онлайн, источники ЦБ РФ и НБ РК), базы обновляются автоматически. Следующий основной этап — v0.3 «Ставки». Подробная история изменений — [CHANGELOG.md](../CHANGELOG.md).

## ✅ v0.1 — FX Forecast Terminal, локальный

- Курсы 54 валют ЦБ РФ, база 10 лет, окна 6М–10Л.
- Ансамблевый прогноз, тренд, волатильность.
- Локальная база + дельта + «Сохранить базу»; работа с file:// без сети.

## ✅ v0.2 — Онлайн-версия на GitHub Pages

- GitHub Pages (корень `main`) — https://ygadalov.github.io/macropulse/.
- GitHub Actions: ежесуточная догрузка дельты с зеркала → коммит `fx-history.js`; догрузка пробует каждый календарный день (архив ЦБ сам является календарём), праздники и переносы выходных не требуют захардкоженных правил.
- Каркас терминала: складной рельс разделов, заглушки ZC / KR / CPI, контекстные настройки, справка и тикер.

## ✅ v0.2.x — Аналитика и UX FX (завершено поверх v0.2)

- Метка T+1: свежая установка ЦБ видна вечером того же дня (бейдж, пунктирный хвост на графике).
- Прогноз с полосой 90 % числами по дням; строки (вс)/(пн) — действие субботней установки.
- Средние по периодам (месяц/квартал/год): календарный средний курс + годовая волатильность с цветовой градацией.
- Курсы в формате ЦБ (4 знака), курсы субботних установок не теряются.
- Компоновка «в один экран» на десктопе, адаптив до телефона (горизонтальная прокрутка вместо сжатия).
- Отключаемые индикаторы MA20/50/200 на графике (чипы в легенде, по умолчанию выключены) и шестая карточка статистики «Откл. от MA50».
- Второй источник курсов — Национальный банк Казахстана: выбор «ЦБ РФ / НБ РК» выпадающим списком, 48 валют к тенге с 2016 года, база обновляется ежесуточным GitHub Action (CORS API НБК закрыт — без браузерной догрузки).
- Экспорт CSV: динамика текущего окна, таблица прогноза и средние по периодам; формат совместим с Excel RU.
- Выбранная дата (pin-date): клик по графику или ручной ввод даты пересчитывает курс в шапке и шесть карточек статистики; прогноз, средние и тренд остаются привязанными к полному окну.
- Ручной период анализа «с/по»: для исторического диапазона панель прогноза заменяется «Итогами периода» (изменение, экстремумы, дрейф, R², волатильность); pin-date работает и внутри ручного диапазона.
- Лента показателей: бегущая, статичная с ручной прокруткой и скрытая; выбор сохраняется, при скрытии высота передаётся рабочей области без изменения карточек и панели управления.
- Подпись разработчика в статус-баре по брендбуку Gadalov BI.

**Очередь обязательных доработок FX закрыта; новые идеи не блокируют переход к v0.3.**

## v0.3 — Раздел «Ставки» (ОФЗ)

- Кривая бескупонной доходности (MOEX ISS zcyc, история с 2014): график кривой, «сейчас vs год назад».
- Ключевая ставка ЦБ (история решений) и базовая ставка НБК (с коридором ±1 п.п.).
- Календарь заседаний по ставке (ЦБ РФ + НБК): ближайшая дата, тип события (заседание / пресс-конференция / резюме), «через N дн.». Источники проверены 12.11.2026: история КС — SOAP cbr.ru DailyInfo/KeyRate (с 2013); календарь ЦБ — парсинг cbr.ru/dkp/cal_mp/ (JSON нет); история базовой ставки НБК — JSON data.nationalbank.kz/api/v1/data/base-rate (без ключа, только ~15 последних записей — бэкфилл таблицей nationalbank.kz 2015–2026) + страница графика заседаний КДКП; CORS у API НБК закрыт — сбор только ежедневным GitHub Action в kr-history.js (как kzt-history.js).
- Аналитика: наклон кривой (10Л−2Л), инверсия, ожидания по ставке из короткого конца.

### Прогноз ключевой ставки — методология (обсуждено 26.11.2026)

- **Результат:** не одна детерминированная точка, а ожидаемая траектория ключевой ставки по датам заседаний ЦБ, вероятности дискретных исходов и историческая точность метода.
- **Входные данные:** котировки RUONIA OIS (ROIS/RUSFAR, сроки 1W–1Y), фактическая RUONIA, история ключевой ставки, календарь заседаний ЦБ и, при доступности, опросы аналитиков как независимый бенчмарк.
- **Контроль качества:** отбрасывать устаревшие, неликвидные и аномальные котировки; фиксировать дату и качество входного среза, не выдавать разреженный рынок за надёжный сигнал.
- **Форвардная кривая:** при достаточной ликвидности строить форварды непосредственным бутстрэппингом по инструментам; параметрическую модель Нельсона–Сигеля использовать только как стабилизированный резерв при пропусках и на неликвидных участках.
- **Премия за срок:** оценивать спред OIS против реализованной RUONIA на скользящих окнах и отдельно по фазам ставочного цикла; не использовать один постоянный коэффициент. Нестабильные оценки сжимать к долгосрочному среднему или нулю.
- **Базис RUONIA ↔ ключевая ставка:** моделировать отдельно от премии за срок и учитывать его возможную зависимость от ликвидности и режима рынка.
- **Перевод в ставку:** решать обратную задачу для кусочно-постоянной ожидаемой ключевой ставки между заседаниями; затем оценивать вероятности дискретных исходов (снижение / без изменений / повышение и шаги изменения).
- **Проверка:** expanding-window бэктест без подглядывания вперёд, сравнение с наивным прогнозом «ставка не изменится» и опросами аналитиков; отдельно проверять кризисные эпизоды 2014 и 2022 годов и качество калибровки вероятностей.
- **Критерий публикации:** если метод устойчиво не превосходит наивный бенчмарк, публиковать только «рыночные ожидания» как индикатор, а не как собственный прогноз.
- **Возможная реализация после отдельного одобрения:** ежедневный GitHub Action → сгенерированный `kr-forecast.js`, с проверкой доступности, лицензий и стабильности источников. Запись методологии не означает разрешения на разработку модуля.

## Идеи (парковка)

- GARCH-полоса прогноза, бэктест-метрики моделей.
- ARIMA(0,1,1) четвёртым членом ансамбля прогноза (эквивалент Theta уже внутри; проверить выигрыш на бэктесте).
- Автоповтор запросов при временных ошибках зеркала ЦБ и более мягкий UX состояния загрузки/ошибки.
- Фоновая догрузка истории без блокировки интерфейса.
- Z-score-нормировка отклонения от MA50 для сопоставимости сигнала между валютными парами и режимами волатильности.
- Выбор формата CSV/XLSX при экспорте (сейчас реализован CSV).
- Кастомизация тикера (выбор валют для бегущей строки из 54 доступных).
- Watchlist-монитор с сигналами.
- Прогноз формы кривой (динамический Нельсон–Сигель по параметрам ZCYC).

Пункты парковки — необязательные идеи, а не утверждённый план разработки; реализация — после отдельного обсуждения.
