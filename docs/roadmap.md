# Roadmap MacroPulse

Ценность проекта — анализ и прогноз, а не показ данных. Каждый этап добавляет класс данных **вместе с аналитикой** по нему.

Статус на 12.11.2026: работает раздел FX (локально и онлайн, источники ЦБ РФ и НБК), базы обновляются автоматически. Подробная история изменений — [CHANGELOG.md](../CHANGELOG.md).

## ✅ v0.1 — FX Forecast Terminal, локальный

- Курсы 54 валют ЦБ РФ, база 10 лет, окна 6М–10Л.
- Ансамблевый прогноз, тренд, волатильность.
- Локальная база + дельта + «Сохранить базу»; работа с file:// без сети.

## ✅ v0.2 — Онлайн-версия на GitHub Pages

- GitHub Pages (корень `main`) — https://ygadalov.github.io/macropulse/.
- GitHub Actions: ежесуточная догрузка дельты с зеркала → коммит `fx-history.js`; догрузка пробует каждый календарный день (архив ЦБ сам является календарём), праздники и переносы выходных не требуют захардкоженных правил.
- Каркас терминала: складной рельс разделов, заглушки ZC / KR / CPI, контекстные настройки, справка и тикер.

## ✅ v0.2.x — Аналитика FX (выпущено поверх v0.2)

- Метка T+1: свежая установка ЦБ видна вечером того же дня (бейдж, пунктирный хвост на графике).
- Прогноз с полосой 90 % числами по дням; строки (вс)/(пн) — действие субботней установки.
- Средние по периодам (месяц/квартал/год): календарный средний курс + годовая волатильность с цветовой градацией.
- Курсы в формате ЦБ (4 знака), курсы субботних установок не теряются.
- Компоновка «в один экран» на десктопе, адаптив до телефона (горизонтальная прокрутка вместо сжатия).
- Отключаемые индикаторы MA20/50/200 на графике (чипы в легенде, по умолчанию выключены).
- Второй источник курсов — Национальный банк Казахстана: переключатель ЦБ РФ / НБК в панели пары, 48 валют к тенге с 2016 года, база обновляется ежесуточным GitHub Action (CORS API НБК закрыт — без браузерной догрузки).

## Следующие шаги по FX (перед новыми разделами)

- Экспорт данных в CSV (история/прогноз по текущей паре и окну).
- Pin-date: кросс-фильтр панелей по выбранной на графике дате.
- Ручной период анализа: «Итоги периода» по произвольному диапазону дат.

## v0.3 — Раздел «Ставки» (ОФЗ)

- Кривая бескупонной доходности (MOEX ISS zcyc, история с 2014): график кривой, «сейчас vs год назад».
- Ключевая ставка ЦБ (история решений).
- Аналитика: наклон кривой (10Л−2Л), инверсия, ожидания по ставке из короткого конца.

## v0.4 — Макро

- Инфляция (CPI), RUONIA.
- Реальная ставка (ключевая − инфляция) и её связь с рублём.

## v0.5 — Рынки MOEX

- Индексы IMOEX, RGBI; агрегаты по сегментам облигаций.
- Отдельные бумаги ОФЗ — по запросу (не хранить все ~250 подневно).

## Идеи (парковка)

- GARCH-полоса прогноза, бэктест-метрики моделей.
- ARIMA(0,1,1) четвёртым членом ансамбля прогноза (эквивалент Theta уже внутри; проверить выигрыш на бэктесте).
- Кастомизация тикера (выбор валют для бегущей строки из 54 доступных).
- Watchlist-монитор с сигналами.
- Прогноз формы кривой (динамический Нельсон–Сигель по параметрам ZCYC).
