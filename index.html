Раздел: FX Forecast

Модель

Краткосрочный прогноз — ансамбль из трёх моделей по логарифму курса: сглаживание Холта с затухающим трендом, Theta-метод и наивный дрейф; итоговая точка — медиана трёх. Полоса 90% — из робастной σ одношаговых ошибок (MAD) плюс разброс между моделями: чем сильнее они расходятся, тем шире полоса. Долгосрочный тренд — лог-линейная регрессия за всё окно. Прогноз строится по дням установки курса ЦБ РФ (вторник–пятница, без госпраздников); в эти же дни попадают и прогнозные точки.

По умолчанию параметры Холта подбираются автоматически под историю пары. Их можно задать вручную: кнопка-микшер в шапке (слева от этой справки) → «Параметры Холта» → режим ВРУЧНУЮ. Ручной режим меняет только член Холта — ансамбль из трёх моделей сглаживает крайние значения.

Источник

Все котировки — официальные курсы ЦБ РФ (cbr.ru, 54 валюты). Кросс-курсы без рубля считаются через рублёвые курсы обеих валют. Это локальная версия: вся история (10 лет) лежит рядом с приложением в файле fx-history.js, поэтому график открывается мгновенно и полностью без сети. Если есть интернет, при открытии догружаются только новые дни с открытого JSON-зеркала курсов (cbr-xml-daily.ru) — обычно это 1–3 запроса. Новые данные копятся в браузере; кнопка «Сохранить базу» в настройках (шестерёнка справа вверху → «Локальная база») перезаписывает fx-history.js уже с ними, чтобы база жила в файле и переносилась вместе с папкой на любой ПК. Ключи и VPN не требуются. Прогноз носит статистический характер и не является инвестиционной рекомендацией.

Zero Curve

Раздел в разработке. Здесь будет кривая бескупонной доходности ОФЗ (ZCY Curve) по данным MOEX ISS: форма кривой, сдвиги за день/неделю/месяц, наклон 10Y−2Y и история ключевых сроков. Справка появится вместе с разделом.

Key Rate

Раздел в разработке. Здесь будет история ключевой ставки ЦБ РФ, календарь заседаний Совета директоров, сопутствующие ставки (RUONIA) и сигналы из пресс-релизов. Справка появится вместе с разделом.

CPI

Раздел в разработке. Здесь будет инфляция: ИПЦ год к году и месяц к месяцу (Росстат / ЦБ РФ), отклонение от цели ЦБ 4,0%, компоненты и сезонность. Справка появится вместе с разделом.
